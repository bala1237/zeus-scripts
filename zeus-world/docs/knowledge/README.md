# Zeus World: knowledge

How each part works and how it was built. One file per topic. Update the file in the same commit as any change to its area; add a new file when a new area appears, and list it here.

| File | Covers |
| --- | --- |
| `city-scene.md` | The city scene: files, page options, layout, lighting, time of day, citizens, construction, ambient motion, effects |
| `models.md` | How models are made: Blender scripts, fal generation, Poly Haven, the normaliser, naming, budgets |
| `characters.md` | The citizens: rigs, animations, how to check an animation with a frame sheet, how a broken binding was repaired |
| `battle.md` | The siege at the south gate: what it shows, how to see it, how it is driven and built |
| `hosting.md` | The Vercel preview, how to deploy, branches and merging |
| `environment.md` | Setting up a session: Blender, Node, rendering stills, connected services and their limits |
| `performance.md` | Memory and frame rate: what is known, how to measure, what has been tried |

Related documents outside this folder: `../CONSTITUTION.md` (product rules), `../ASSET-BIBLE.md` (style rules, catalogue, socket table), `../../assets/README.md` (pipeline commands in full).
